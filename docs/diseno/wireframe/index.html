Anotaciones — Pantalla 1 · Login

Decisiones de diseño de esta pantalla, ancladas en la Alternativa C y en hallazgos del TP2.
Mapa de navegación del flujo principal:
Login → Home → Cargar trayecto → Confirmación → Home (esperando) → Solicitud entrante → Aceptar → Mi viaje → Iniciar viaje → Llegada → Finalizar → Cierre.

Los botones marcados "(demo)" no forman parte del producto final: simulan eventos que en la app real dispararía otro usuario (una solicitud) o el GPS (la llegada), para poder recorrer el flujo completo en este wireframe estático.
